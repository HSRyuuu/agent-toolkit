# Markdown → Jira/Confluence 변환 규칙

마크다운 문서를 티켓 코멘트·설명이나 위키 페이지로 옮길 때 쓴다. 스크립트가
`--body` / `--description` 평문을 Jira는 ADF로, Confluence는 storage XHTML로
변환한다. **변환기가 모르는 문법은 사라지지 않고 원문 그대로 노출된다** —
` ```json `이 글자 그대로 찍히고 코드가 문단으로 흩어지는 식이다. 그래서 넘기기
전에 아래 표를 기준으로 원문을 손봐야 한다.

## 지원하는 문법

| 마크다운 | Jira (ADF) | Confluence (storage) |
| --- | --- | --- |
| `# `~`###### ` | heading level 1~6 | `<h2>`~`<h6>` (페이지 제목이 h1) |
| 빈 줄로 구분된 문단 | paragraph | `<p>` |
| 문단 안 줄바꿈 | hardBreak | `<br />` |
| `- ` / `* ` | bulletList | `<ul>` |
| `1. ` / `1) ` | orderedList | `<ol>` |
| `> ` | blockquote | `<blockquote>` |
| ` ```lang ` 펜스 | codeBlock (language 유지) | code 매크로 (language 유지) |
| 파이프 표 + `\|---\|` 구분행 | table | `<table>` |
| `` `코드` `` | code 마크 | `<code>` |
| `**굵게**` | strong 마크 | `<strong>` |
| `[라벨](https://…)` | link 마크 | `<a href>` |
| `` **`굵은 코드`** `` | code만 (아래 참조) | `<strong><code>` |

**ADF의 `code` 마크는 다른 서식 마크와 공존할 수 없다.** `` **`type`으로 분기** ``
처럼 굵게 안에 코드가 있으면 코드 부분은 code 마크만 남고 굵게가 빠진다. 둘 다
보내면 Jira가 `INVALID_INPUT` 400을 던진다. Confluence는 제약이 없어 둘 다 적용된다.

## 지원하지 않는 문법 — 넘기기 전에 고친다

| 마크다운 | 결과 | 대응 |
| --- | --- | --- |
| `*기울임*`, `_기울임_` | 별표·밑줄 그대로 노출 | 굵게로 바꾸거나 뗀다. 불릿·식별자와 충돌해 일부러 안 받는다 |
| `[라벨](#앵커)`, `[라벨](./경로)` | 라벨만 남고 링크는 사라진다 | 문서 내부 앵커는 원본에서만 유효하다. 필요하면 전체 URL로 바꾼다 |
| `![alt](경로)` 이미지 | 경로가 글자로 노출 | `attach`로 올린 뒤 첨부 문법으로 넣는다 (`write-guide.md`) |
| 중첩 목록 (들여쓴 `- `) | 한 단계로 평탄화 | 항목을 풀어 쓰거나 표로 바꾼다 |
| 목록 항목 안의 여러 문단·코드블록 | 첫 줄만 항목이 되고 나머지는 분리된다 | 항목을 한 줄로 줄인다 |
| `---` 수평선 | 문단으로 노출 | 지우거나 제목으로 바꾼다 |
| `~~취소선~~`, 각주, 정의 목록 | 그대로 노출 | 뗀다 |
| 표 안의 줄바꿈 (`<br>`) | 글자로 노출 | 셀을 한 줄로 줄이거나 표를 쪼갠다 |
| 표 셀 안의 코드블록 | 깨진다 | 표 밖으로 뺀다 |
| HTML 태그 | Jira는 글자로 노출, Confluence는 이스케이프됨 | 마크다운으로 바꾼다. Confluence는 `--storage`로 직접 쓸 수 있다 |
| 마크다운 각주/TOC/frontmatter | 그대로 노출 | 뗀다 |

## 옮기기 전 체크리스트

긴 문서를 코멘트나 페이지로 옮기기 전에 다음을 확인한다.

1. **표 구분행** — 모든 표에 `|---|---|` 행이 있는가. 없으면 표로 인식되지 않고
   파이프가 그대로 노출된다.
2. **코드 펜스 짝** — 여는 펜스마다 닫는 펜스가 있는가. 닫히지 않으면 문서 끝까지
   코드블록으로 먹힌다.
3. **셀 안의 `|`** — `\|`로 이스케이프했는가.
4. **frontmatter·TOC·수평선** — 원본 문서용 장식은 뗐는가.
5. **내부 링크** — `#앵커`, 상대 경로 링크가 남아 있는가. 라벨만 남으므로 의미가
   통하는지 확인한다.
6. **이미지** — 본문에 이미지가 있으면 먼저 `attach`로 올리고 첨부 문법으로 건다.

## 원문을 그대로 유지해야 할 때

변환을 거치면 안 되는 원본 서식이 있으면 우회 경로를 쓴다.

- **Confluence** — `--storage`로 storage XHTML을 직접 넘긴다. 매크로, 확장,
  레이아웃처럼 마크다운으로 표현할 수 없는 것에 쓴다.
- **Jira** — ADF 직접 입력 경로는 없다. 위 표 안에서 표현하거나, 원문 파일을
  `attach`로 첨부하고 본문에는 요약만 남긴다.

긴 본문은 셸 인용 문제를 피해 `--body-file <path>` 또는 `--body-file -`(stdin)로
넘긴다.

## 확인

쓰기 전에 변환 결과를 미리 볼 수 있다.

```bash
python3 -c "import sys; sys.path.insert(0, '<SKILL_DIR>/scripts'); \
import atlassian_common as c, json; \
print(json.dumps(c.text_to_adf(open('doc.md').read()), ensure_ascii=False, indent=2))"
```

쓰고 난 뒤에는 `jira.py issue <KEY> --comments 1`이나
`confluence.py page <ID>`로 읽어 확인한다. 평문 변환 결과에 `` ` ``, `**`,
` ``` `, `| ` 같은 마크다운 기호가 남아 있으면 그 문법이 변환되지 않은 것이다.
