# ux-writing

> 웹 화면에 들어갈 텍스트를 쓰거나 고친다. 새로 쓸 때도, 기존 문구를 고칠 때도
> 같은 원칙으로 판정한다.

## 원칙

판정과 작성 모두 이 표 하나를 기준으로 한다. 위반은 ID로 기록한다.

| ID | 원칙 | 위반 신호 |
|---|---|---|
| W1 | 사용자가 하는 일이나 기다리는 대상을 주어로 쓴다 | 시스템·서버·데이터가 주어 |
| W2 | 사용자가 얻는 것으로 말한다 | "놓치면", "손해", "마지막 기회" |
| W3 | 확인할 수 있는 사실만 말한다 | 감정 단정, 근거 없는 최상급·수치 ("업계 1위") |
| W4 | 한 문장에 정보 하나 | 조건·숫자가 셋 이상 이어진 문장 |
| W5 | 같은 말을 두 번 하지 않는다 | 제목·부제·본문이 표현만 다른 같은 주장 |
| W6 | 막힌 상황은 원인과 다음 행동을 함께 말한다 | "오류가 발생했습니다", 에러 코드만 노출 |
| W7 | 버튼·링크는 누르면 일어나는 일을 말한다 | 맥락 없는 "확인"·"완료"·"여기를 클릭" |
| W8 | 한 흐름 안에서 표기를 하나로 맞춘다 | 어투 혼용, `1000원`/`1,000원` 혼용, 한 대상에 두 이름 |
| W9 | 한 언어로 쓴다 | 한국어 문장 속 `Submit`·`Error` |
| W10 | 선택을 왜곡하지 않는다 | 거절 버튼 깎아내리기, 근거 없는 시간 압박, 숨긴 비용 |

막힌 상황은 에러, 빈 결과, 권한 거부를 포함한다. 알림을 닫기만 하는 "확인"은 W7
위반이 아니다. 고유명사와 브랜드명은 W9 예외다. 어투(습니다체·해요체)는 고르지
않는다. 기존 화면의 어투를 따르고, 새 서비스라 기준이 없으면 사용자에게 묻는다.

## 작업 절차

**새로 쓸 때** — 화면의 목적, 사용자가 이 화면에 오기 직전 상황, 다음에 할 행동을
먼저 정한다. 그다음 요소별로 쓰고, 정상 상태만이 아니라 로딩·빈 결과·에러 상태
문구까지 함께 낸다. 결과는 `요소 | 문구 | 비고` 표로 준다.

**기존 문구를 고칠 때**
1. 대상 화면에서 사용자 문구를 모아 `화면 | 위치 | 원문`으로 정리한다. 대상이
   없으면 프로젝트 화면 문구를 먼저 훑고 범위를 사용자와 정한다.
2. 문구마다 W1~W10을 대조한다. 통과한 문구는 손대지 않는다.
3. 위반 문구만 고치고, 고친 문구를 표 전체에 다시 대조해 새 위반이 없을 때만 낸다.
4. `위치 | Before | After | 바뀐 점 (ID)` 표로 제안한다. 길어진 문구가 줄 수 제한·
   고정 폭·말줄임이 걸린 자리에 있으면 비고로 짚는다.
5. 승인한 항목만 반영한다. 문자열 밖은 건드리지 않는다. 일부만 반영하면 화면 안
   표기가 섞일 수 있으니 W8로 한 번 더 훑는다.

브랜드 문구 정책, 법률·약관 문구의 적법성은 판단하지 않는다. 확신이 없으면
지어내지 않고 사용자에게 확인한다.

## 예시

**로딩** — W1
- Before: "요청을 처리하고 있어요."
- After: "주문 내역을 불러오고 있어요."

**빈 결과** — W6
- Before: "데이터가 없습니다."
- After: "저장한 글이 없습니다. 글 상단의 북마크를 누르면 여기에 모입니다."

**업로드 실패** — W6, W9
- Before: "Upload failed (413)"
- After: "사진이 10MB를 넘어 올리지 못했어요. 크기를 줄이거나 다른 사진을 골라 주세요."

**폼 검증** — W6
- Before: "형식이 올바르지 않습니다."
- After: "휴대폰 번호는 숫자만 입력해 주세요. 예: 01012345678"

**버튼** — W7
- Before: "완료"
- After: "배송지 저장"

**거절 선택지** — W2, W10
- Before: "알림 받기" / "아니요, 혜택은 필요 없어요"
- After: "알림 받기" / "나중에"

**조건 안내** — W4, W10
- Before: "무료 체험은 7일간이며 종료 후 월 9,900원이 자동 결제되고 종료 하루 전까지
  해지하면 청구되지 않아요."
- After:

  ```
  7일 동안 무료로 써 볼 수 있어요.
    · 체험이 끝나면: 매월 9,900원 자동 결제
    · 요금 없이 해지: 체험 종료 하루 전까지
  ```
