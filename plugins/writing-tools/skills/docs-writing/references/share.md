# 내용공유

독자가 읽고 알기만 하는 문서. 행동을 요구하지 않는다. 조사·분석 결과 공유, 변경
안내, 현황 정리가 여기 속한다.

## 여는 블록

제목 밑 한 문장 요약 다음 줄에 `기준일 · 출처`를 한 줄로 적는다. 여는 블록에는
표를 만들지 않는다.

특정 팀·역할에만 해당하는 내용이면 요약 문장 안에 누구에게 해당하는지 넣는다.

## 섹션 순서

아래는 주장이 있는 공유 문서의 기본 순서다. 해당하는 것만 고른다. 자료가 중립적
기록(무엇이 바뀌었는지, 어떻게 동작하는지)이면 결론·한계를 지어내지 않고 원본의
구조를 유지한다.

1. **결론** — 알아야 할 것. 문서에서 가장 짧아야 하고 가장 먼저 나온다.
2. **근거** — 결론을 받치는 사실. 표 하나로 끝나는 경우가 많다.
3. **영향받는 곳** — 이 사실 때문에 달라지는 것. 없으면 생략한다.
4. **한계** — 이 결과를 어디까지 믿어도 되는지. 두세 줄.

섹션 수와 분량은 제한하지 않는다. 다만 독자에게 결정을 요구하는 섹션이 늘면
보고서로 쓸 것이었는지 다시 본다.

## 유형 특유 안티패턴

**행동 요구가 없는데 훈수** — "따라서 우리는 ~해야 한다"가 붙는다. 결정 권한이
없는 문서에서 이 문장은 무게가 없다. 대신 사실만 두고, 결정이 필요하면 보고서로
쓴다.

**조사 과정 서술** — 어떻게 알아냈는지를 시간 순으로 쓴다. 대신 알아낸 것만
남기고 과정은 원본 자료에 둔다.

**배경이 결론보다 김** — 독자는 이미 맥락을 안다고 가정한다. 대신 배경은 한 문단
안에.

**모두에게 보내면서 특정 팀 디테일 포함** — 절반의 독자에게 무의미한 내용이
섞인다. 대신 공통만 남기고 세부는 해당 팀에 따로 준다.

**단정할 수 없는 것을 단정** — 표본이 좁거나 시점 스냅샷인데 일반화한다. 대신
어느 범위까지의 사실인지 문장에 넣는다.
