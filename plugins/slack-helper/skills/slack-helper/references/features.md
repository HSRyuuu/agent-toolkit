# slack-helper 기능 목록과 필요 권한

이 문서는 **권한 안내의 단일 출처**다. 아래 경우에 이 문서의 표를 사용자에게 그대로 보여준다.

- 사용자가 "기능 목록", "뭘 할 수 있어?", "권한 뭐 필요해?"라고 물을 때 → `## 기능 목록` 표 + 현재 상태(아래 "켜짐 확인")
- 최초 설치·재설치·기능 추가로 권한을 안내할 때 → `## 필수 권한` 표를 먼저, 필수가 끝나면 `## 선택 기능` 표에서 고르게 한다 (절차는 `setup-guide.md`)
- 권한 부족(`missing_scope` 등)으로 작업이 실패했을 때 → `## 기능 목록`에서 실패한 기능의 행을 짚고, 그 행의 선택 묶음을 켜도록 안내한다

권한은 **필수**(처음부터 항상 요청)와 **선택**(쓰려는 기능 묶음만 요청)으로 나뉜다. 선택 권한은 `slack_setup.py oauth-start --features <묶음 키,…>`로 요청에 더하며, 한 번 고른 묶음은 config에 저장돼 재설치 때도 유지된다. "scope(권한)"는 이 앱이 Slack에서 무엇을 할 수 있는지 정하는 허가 목록이라고 한 줄로 풀어 설명한다.

## 필수 권한

읽기·검색의 기본이다. 최초 설치 때 모두 추가한다.

**봇 토큰 범위 (Bot Token Scopes)** — 앱이 워크스페이스에서 직접 하는 일

| 권한 | Slack 설명 | 켜면 할 수 있는 일 |
| --- | --- | --- |
| `team:read` | 워크스페이스의 이름·이메일 도메인·아이콘 보기 | 워크스페이스 기본 정보 확인 |
| `users:read` | 워크스페이스의 사람 보기 | 작성자·`@멘션`을 실제 이름으로 표시, DM 상대 이름 찾기 |
| `channels:read` | 공개 채널의 기본 정보 보기 | 공개 채널 목록 조회, 채널 이름 → ID 찾기 |
| `channels:history` | 앱이 추가된 공개 채널의 메시지·콘텐츠 보기 | 공개 채널 히스토리·스레드 직접 읽기 |

**사용자 토큰 범위 (User Token Scopes)** — 나(사용자)를 대신해 하는 일

| 권한 | Slack 설명 | 켜면 할 수 있는 일 |
| --- | --- | --- |
| `search:read` | 워크스페이스의 콘텐츠 검색 | **메시지 검색** (봇 토큰만으로는 불가, 검색의 필수 권한) |
| `channels:read` | 공개 채널의 기본 정보 보기 | 공개 채널 이름 → ID 해석 |
| `channels:history` | 내 공개 채널의 메시지·콘텐츠 보기 | 공개 채널 히스토리·스레드 읽기(봇 실패 시 대체) |
| `groups:read` | 내 비공개 채널의 기본 정보 보기 | 내가 속한 비공개 채널 목록·이름 → ID |
| `groups:history` | 내 비공개 채널의 메시지·콘텐츠 보기 | 비공개 채널 히스토리·스레드 읽기 |

## 선택 기능

쓰고 싶은 것만 고른다. **묶음 키**는 `--features`에 넘기는 값이다. 모두 사용자 토큰 범위(User Token Scopes)다.

| 묶음 키 | 추가할 권한 | Slack 설명 | 켜면 할 수 있는 일 |
| --- | --- | --- | --- |
| `send` | `chat:write` | 나를 대신하여 메시지 보내기 | 채널에 메시지 게시, 스레드 답글, DM 전송 |
| `react` | `reactions:write` | 나를 대신하여 이모지 리액션 추가 | 메시지에 이모지 달기 |
| `dm` | `im:read` | 내 DM의 기본 정보 보기 | 1:1 DM 목록 조회, 상대 이름 → DM 찾기 |
| | `im:history` | 내 DM의 메시지·콘텐츠 보기 | 1:1 DM 대화 읽기 |
| | `im:write` | DM 시작하기 | 아직 대화가 없는 사람에게 DM 보내기 |
| | `mpim:read` | 내 그룹 DM의 기본 정보 보기 | 그룹 DM 목록 조회 |
| | `mpim:history` | 내 그룹 DM의 메시지·콘텐츠 보기 | 그룹 DM 대화 읽기 |
| `files-read` | `files:read` | 내가 볼 수 있는 파일 보기 | 파일 목록 조회, 다운로드 |
| `files-write` | `files:write` | 파일 올리기·수정·삭제 | 내 이름으로 파일 업로드 |

## 기능 목록

| 기능 | 설명 | 필요 권한 | 구분 |
| --- | --- | --- | --- |
| 메시지 검색 | 키워드·사람·채널·기간으로 메시지를 찾는다. 멘션 정리, 장애 타임라인, 주간 리포트, 데일리 리뷰의 바탕이다. | `search:read` | 필수 |
| 채널·스레드 읽기 | 공개·비공개 채널의 히스토리(날짜 범위 지원)와 스레드를 읽는다. | 필수 권한 전체 | 필수 |
| 사용자·채널 목록 | 사용자·채널 목록을 보고, 이름·`@멘션`을 실제 이름으로 표시한다. | `users:read`, `channels:read` | 필수 |
| 채널·스레드 메시지 보내기 | 채널에 새 글을 쓰거나 스레드에 답글을 단다. 내 이름으로 게시되고 보내기 전 확인을 받는다. | `chat:write` | 선택 `send` |
| 이모지 달기 | 메시지에 이모지 리액션 하나를 단다. | `reactions:write` | 선택 `react` |
| DM 목록·조회 | 내 1:1 DM·그룹 DM 목록을 보고 대화를 읽는다(특정 사람과 나눈 DM, 날짜 범위). | `im:read`, `im:history`, `mpim:read`, `mpim:history` | 선택 `dm` |
| DM 보내기 | 특정 사람에게 1:1 DM을 보낸다. 대화가 없으면 새로 연다. | `chat:write` + `im:read`, 새 대화는 `im:write` | 선택 `send` + `dm` |
| 파일 목록·다운로드 | 메시지에 달린 첨부 파일을 조회하고 내려받는다. 해당 대화를 읽을 권한(채널은 필수, DM은 `dm`)도 필요하다. | `files:read` | 선택 `files-read` |
| 파일 업로드 | 로컬 파일을 채널·스레드·DM에 올린다. 올리기 전에 파일·대상 확인을 받고, 설정 폴더 파일은 거부한다. DM 대상은 `dm`(`im:read`, 새 대화는 `im:write`)도 필요하다. | `files:write` | 선택 `files-write` |

**지원하지 않는 일:** 메시지 수정·삭제, 리액션 제거, Slack "해야 할 일(To-dos)" 화면(공식 API 없음).

## 켜짐 확인

`slack_setup.py doctor`의 `선택 기능 켜짐: … / 꺼짐: …` 줄이 현재 승인된 선택 묶음을 알려준다. 기능 목록을 보여줄 때 이 결과로 각 선택 기능이 켜졌는지 함께 표시한다. 필수 권한이 빠지면 같은 출력에 `User scope 부족` 경고가 나온다.
